# 可编辑 QGIS 路线

这是可选的操作规范，不是已经运行的 QGIS 工程生成器。附带 Python 静态程序不生成 `.qgz`。只在任务确需工程编辑、环境可用且操作已有授权时使用此路线。

## 接入

先确认本次客户端实际提供的 QGIS 工具，不能猜测工具名；可用时使用真实的轻量诊断。只有应用文件存在而没有连接，不得声称已连接。也可在有执行授权且配置正确的 QGIS Python 环境中使用 PyQGIS，不要求 MCP 必须存在。

读现有工程前确认用户授权范围；创建新工程而非清空当前工程。所有衍生数据放入独立交付目录；输入、配置和来源记录复用本技能契约。

## 布局顺序

1. 建立具名工程，读取真实图层，检查有效性、CRS、属性、范围和年份。
2. 对每个地图框明确显示图层、CRS、范围和必要旋转；不能依赖当时画布状态。
3. 创建 `QgsPrintLayout`，初始化页面、设定尺寸，添加到工程布局管理器，使布局可保存。
4. 添加每个 `QgsLayoutItemMap`，显式设置 CRS 和范围。需要从其他 CRS 转换范围时使用具有足够边界采样的转换，并核对最终图幅。
5. 设置图层可见性/样式锁定；上级定位图仅显示所需层，不因主图增加细节而污染小图。
6. 用布局 overview 或经核验的多边形表达另一个地图框的范围，关联真正的目标地图。检查投影、旋转和布局调整后的同步结果。
7. 图例、比例尺与目标地图框绑定。北箭头使用对应地图的真北设置，核对所用版本 API；不要仅放一个未旋转的箭头图片。
8. 设置标题、图注、数据署名，检查实际字号、字体和图层顺序。
9. 等待渲染完成，检查布局导出而不仅是地图画布；分别核对 PNG、PDF、SVG。
10. 检查 `QgsLayoutExporter` 返回码，失败就停止声明交付成功；保存 `.qgz`、关联数据、可选 `.qml` 与完整来源记录。

工程内部数据路径应使用可移植的相对路径。打包前重新打开副本，检查图层和布局；`.qgz` 不是自动包含所有外部数据的容器。包含栅格的 PDF/SVG 不等于完全矢量。

## 已有技能的选择性复用

设计参考了本机 `qgis-map-workflow` 的原件保护、可编辑工程、截图自检，以及 `qgis-impl-print-layouts` 的布局初始化、显式范围、关联比例尺和导出返回码检查。没有复制其中完整代码或将其作为运行依赖。

不继承以下过强假设：按中国经纬度数值范围断定字段、所有出版图使用 EPSG:3857、所有图必须配同样的图面要素、只需添加软件就已具备运行条件。

## 官方核验入口

2026-09-20 浏览核对：[QGIS 3.44 地图渲染与打印](https://docs.qgis.org/3.44/en/docs/pyqgis_developer_cookbook/composer.html)。执行时按实际安装版本检查 API，特别是 overview、真北、字体和 SVG 导出的行为；本次未执行任何 PyQGIS 操作。
