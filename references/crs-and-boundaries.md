# 坐标、投影、定位框和边界

官方文档核查日期：2026-09-20。下述选择规则是本 skill 的制图工作流；期刊和主管部门要求应在实际交付时复核。

## 1. 分开记录三个事实

- `source_crs`：文件/测量数据真实的坐标参考系统，优先保留 EPSG 标识及完整 WKT2。读取值与人工补充值都记录证据。地理坐标、投影坐标、轴顺序及单位不能混同。
- `coordinate_system`：坐标的实际来源约定，例如 `WGS84`、`CGCS2000`、`GCJ-02`、`BD-09` 或 `other`。未知状态先留在调查记录中并停止实图；渲染配置不接受 `unknown`。此字段用于识别第三方数值和文件声明的冲突，不能代替完整 CRS。
- 面板输出 CRS：当前地图框选择的制图投影。多个地图框可以采用不同投影，但它们的地理定位必须一致。

示例：有人把高德拾取的 GCJ-02 经纬度写进声明 EPSG:4326 的 GeoJSON。需将该冲突列为阻断项；不能因为文件 CRS 可解析就认定输入是 WGS84。

## 2. 输入判定与变换

1. 先读可信元数据、测量说明或提供者声明，再用数值范围、单位和控制位置核查一致性。范围只能揭示异常，不能证明 CRS，也不能单凭中国大陆经纬度范围自动交换坐标列。
2. 经纬列含义不明、CRS 缺失/冲突或关键坐标来源不明时暂停受影响图层的实图。继续列出待确认字段、候选解释和布局；不得悄悄设为 EPSG:4326。
3. `set_crs` 只告诉软件如何解释已有数字；`to_crs` 才是坐标变换。只有可靠外部证据支持时才能补缺失标签；不能用改标签修复实际偏移。保留原始 CRS、变换过程和结果。见 [GeoPandas 投影文档](https://geopandas.org/en/stable/docs/user_guide/projections.html)。
4. WGS84 与 CGCS2000 分开处理。CGCS2000 的地理 CRS 为 EPSG:4490，具体高斯投影还涉及带号、中央经线、假东移及单位；不能把所有 CGCS2000 数据都标为 4490。不同基准、实现或历元的影响须与图幅精度相匹配；不承诺两者永远等同、也不承诺任何转换都是厘米级准确。见 [EPSG 官方 CGCS2000 条目](https://epsg.org/crs_4490/China-Geodetic-Coordinate-System-2000.html)（本次核查到官方索引，直接读取未成功）与 [PROJ 大地坐标变换说明](https://proj.org/en/stable/usage/transformation.html)。
5. GCJ-02、BD-09 不按普通 EPSG 重投影处理，不能把它们“转成 4326”仅靠 `to_crs`。优先请求提供同一来源的可靠原始测量坐标；如必须处理偏移，先明确方法、适用范围、误差验证和授权。禁止把未验证的经验逆变换写成精确转换，禁止默认上传样点调用服务。高德使用 GCJ-02、百度使用 BD-09 的区别参见 [高德官方坐标说明](https://developer.amap.com/api/javascript-api-v2/guide/transform/convertfrom)与[百度坐标转换说明](https://lbsyun.baidu.com/docs/webapi?title=geoconv/guide/changeposition)。
6. 重投影后核查至少几个分散的已知地点和边界交叉点，并记录残差或可观察偏移。异常点先列 ID、原始坐标和候选原因；在确认前不无声删除、吸附、挪动或交换列。
7. 转换所需格网不可用、转换精度未知或采用近似操作时写入质量记录；当前无下载授权时禁止联网补格网。不可用的关键转换应中止，不以“无报错”代表正确。

## 3. 按每个地图框选择投影

| 地图框/用途 | 决策规则 |
|---|---|
| 村落、街区、单一城市 | 从适用范围覆盖研究区的本地官方投影或合适 UTM 带起选；核对基准、单位、形变和边界。不能因 `estimate_utm_crs` 返回值就跳过核验。 |
| 跨带、狭长流域或多省域 | 比较区域圆锥等角/等积等候选，按形状、方向及研究用途选取标准纬线和中央经线；参数与理由保存，禁止硬编码一个 UTM 带用于全部区域。 |
| 全国、洲际定位小图 | 以清楚表示相对位置为目标，选择适合该范围的投影；通常可省比例尺，使用经纬网或文字解释位置。不能让小图的简化边界替代主图精细边界。 |
| 在线瓦片背景 | 核对瓦片坐标约定、许可及取得授权。EPSG:3857 是常见显示投影，不是默认距离/面积分析 CRS，也不是所有论文图框的默认投影。 |

UTM 是分带投影，使用范围和参数见 [PROJ UTM 官方说明](https://proj.org/en/stable/operations/projections/utm.html)。切换输出投影不能提高原始数据精度。面积或距离分析另行选择适合的计算方法，不从印刷图上的像素距离推回真实量值。

## 4. 比例尺、真北和定位框

- **比例尺绑定面板**：每个比例尺只服务一个明确的地图框。在目标 CRS 单位、局部比例因子或椭球距离得到验证后生成；经纬度坐标轴的“度”不能直接标为米，EPSG:3857 的图上米也不能直接当作地面米。
- **局部适用性**：广域地图的比例尺可能只在指定位置附近成立。记录标尺锚点和计算方法，必要时标注“图中心附近”，或省略并用经纬网辅助；禁止一个标尺跨三个不同比例的面板。
- **指北针**：轴向上不必然是真北。需要真北时，从锚点沿当地椭球子午线取邻近点，转换到输出 CRS 后确定局部方向；记录锚点。网格北必须标明其含义。大范围地图不存在一个对全图处处成立的真北方向，优先考虑经纬网。
- **定位框**：取子图实际显示范围的边界，在子图坐标系中加密边缘，再变换到父图 CRS；不能只转换两个对角点后画矩形。在曲线投影、跨日期变更线或极区尤其要检查。变换失败或部分超出有效投影域时报告，不画误导性连线。
- **研究区高亮**：高亮真实研究区几何，与定位框分别在图例中表达；不能用主图矩形当成研究区边界。比例尺和指北针的任何手工调整都需再次核对其对应面板。

## 5. 边界语义与时间

1. 每个面图层明确角色：现行行政边界、历史行政边界、研究者划定范围、规划边界、流域/自然边界。样本点集合的凸包不是自动成立的村落边界。
2. 记录有效年份和来源；历史研究不默认使用现行边界。若现行边界只作参考背景，图注清楚说明两种年份与作用。
3. 规划边界说明版本及批准/草案状态；数字化历史地图记录原图年代、配准控制点、误差与不确定区。不得给无法确定的历史边界画“精确行政界”实线。
4. 无效几何先诊断。修复、合并、简化及剔除碎片均操作副本，记录要素数和面积变化；不要把岛屿、多部件边界或飞地误当噪声删除。
5. 行政背景与研究区边界不一致时核对层级、年份和几何来源；不为视觉吻合而拉伸、移位或随意删改界线。

## 6. 中国区域图件的出版核验

对计划公开发表且涉及中国国界、行政界或特定区域表达的图，建立与几何 QA 分开的记录：使用哪份底图、地图版本/审图号、哪些内容被修改、目标期刊要求、适用主管部门说明以及尚待核验项。

- 通过[标准地图服务系统](https://bzdt.tianditu.gov.cn/)或对应省级自然资源部门核对所需范围的边界、岛屿和必要附图表达；不能从未经核对的全球边界默认生成中国出版用图。
- 官方系统说明要求直接使用时标注审图号，并对编辑后的公开使用提出审核要求。具体场景应复核当前服务说明及主管部门要求，不把“底图有审图号”写成新组合图已自动获审；参见[上海市规划和自然资源局的说明](https://ghzyj.sh.gov.cn/hyxw/20230222/c97d40c87fc84a0f8cd414a6bf2b8fb9.html)。
- 只有确实基于对应标准地图且编号已核对时才能写其审图号。不得复制他图编号、虚构批准状态，或在已裁切/叠加/重绘时虚称“底图无修改”。
- 标准地图成图常为 JPG/EPS；不能假定提供可重投影的 GIS 几何。若作为完整定位小图，应保留其边界表达和适用说明；若需要裁切、标注或重构，先记录变更及对应出版处理需求。
- 几何与排版可以完成内部验证，但未完成出版边界核验时，交付记录须写“出版核验待完成”，不标为“已合规”或“可直接投稿”。本 skill 不代替地图审查或提供法律保证。
