# 开发与验证状态

记录日期：2026-09-20。当前状态：`static_review_only`。

第一版已编写技能规范、配置模板及本地绘图辅助程序，并完成文档与代码静态审阅。尚未运行程序、依赖导入、语法编译、技能验证器或真实数据绘图。因此不宣称运行验证通过或图件已经达到出版标准。

## 已编写的内容

- 公开数据、用户数据、混合数据三种工作流。
- 行政区位、地形水系、交通样点三类图件规范。
- 两级/三级地图布局、图例、局部比例尺、真北与定位框。
- 本地空间文件及坐标表输入、CRS与范围检查。
- PNG/SVG/PDF导出、配置副本、来源记录、文件哈希与检查报告。
- 可选QGIS工程流程；辅助静态绘图程序本身不生成QGIS工程。

## 静态审查范围

按仅提供地名、上传边界与未知坐标样点、离线混合数据三个场景进行推演。核对坐标声明、GeoPackage图层选择、Shapefile配套文件、定位关系、局部投影前裁剪、图注、离线输入及新建输出目录保护。此审阅不替代实际运行。

## 待验证

1. Python、GIS依赖和当前平台的兼容性。
2. GeoPackage、GeoJSON、Shapefile ZIP、CSV、Excel、GeoTIFF的真实读取及异常分支。
3. 两级/三级图、字体、标注、比例尺、真北及DEM色带。
4. PNG/SVG/PDF图面与尺寸、复现记录、离线行为。
5. QGIS工程生成、保存、重新打开和关联数据的可移植性。
6. 公开数据端点、许可、年代与研究区覆盖。

每台机器都应单独检查环境，不把开发机器曾经存在的包或应用当作运行条件。依赖安装、数据下载与代码执行按当前用户授权进行。

最小后续验证：准备一组有明确CRS、来源和年份的本地边界与样点，在授权后先检查依赖，再于新目录完成一次离线两级图。其他输入格式和QGIS路线逐项扩展验证，未执行项目继续标明未验证。

详细验收场景见 [质量检查](quality-and-acceptance.md)。
