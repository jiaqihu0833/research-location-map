# 数据入口、来源和可复现记录

官方文档核查日期：2026-09-20。此日期是文档核查日期，不是 GIS 数据获取日期。来源页面和接口会变化，真正获取数据时重新检查版本、服务条款及范围。

## 1. 三种入口

| 模式 | 最小输入 | 可继续的工作 | 缺口处理 |
|---|---|---|---|
| `public` | 明确的地名及上级行政区，或带 CRS 的范围 | 列候选数据、核对边界层级和年份、配置布局 | 同名地、边界年份或研究范围含糊时先消歧；没有获取授权时只给来源与获取计划 |
| `user` | 用户提供的空间文件或带坐标表格 | 检查文件、字段、来源和 CRS，建立图层清单 | 研究区关键边界或坐标来源不明时暂停实图；不能用猜测的行政边界替代 |
| `mixed` | 用户研究区/样点，加公开背景 | 用公开背景表达区域位置，用用户图层表达研究对象 | 对背景和研究图层分别记来源、年份、精度，不合并成一个“数据年份” |

用户只给地名并不自动确定研究边界。地理编码返回的点只代表位置，不能作为市县、村落、历史聚落或规划范围的完整边界。道路、水系的背景缺口可以删减相应要素并说明；研究问题依赖它们时则是阻断项。

## 2. 公开来源选择表

| 来源 | 优先用途 | 选择和限制 |
|---|---|---|
| [Natural Earth](https://www.naturalearthdata.com/about/) | 国家、洲际概览及低细节定位小图 | 1:10 million、1:50 million、1:110 million 为编制比例尺等级，`10m` 不是 10 米栅格精度；不替代村落/街区边界。数据为公有领域；其国界表达使用事实控制线等约定，不能默认满足特定出版场景的国界要求。 |
| [geoBoundaries API](https://www.geoboundaries.org/api.html) | 有元数据的国家及各级行政背景 | 优先考察 `gbOpen`，按其 CC BY 4.0 要求署名；其他发布类型许可不同。记录发布版本、具体边界有效年份、ADM 层级、来源和构建日期。ADM 数字不能机械等同所有国家的省/县/乡，逐国核对。`current` 只是动态入口，不是可复现版本号。 |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | 道路、铁路、水系、建筑和兴趣点背景 | 采用 ODbL，图件及再分发数据按适用条款署名；数据库许可与瓦片服务条款分别核查。样区覆盖完整性、分类一致性和更新状况需检查，不能把空白区域解释为地物不存在。 |
| [OSMnx 官方说明](https://osmnx.readthedocs.io/en/stable/getting-started.html) | 获授权后按地名、范围或多边形获取 OSM | 是可选获取工具，不是独立数据源或绘图必需依赖。记录查询范围、标签、端点、时间、缓存及网络简化选项。历史快照配置见 [OSMnx settings](https://osmnx.readthedocs.io/en/stable/user-reference.html#module-osmnx.settings)；数据库当时记录不等于地物当时一定存在或不存在。 |
| [自然资源部标准地图服务系统](https://bzdt.tianditu.gov.cn/)及省级自然资源部门 | 中国区域边界表达核验、适用的标准地图底图 | 区分成图产品与可分析的矢量 GIS 数据。不要承诺全国村级数据、矢量下载或自由改图。2026-09-20 核查到官方搜索索引说明，直接页面读取未成功；实际使用须重验入口、使用说明和审图号。 |
| [USGS The National Map](https://www.usgs.gov/programs/national-geospatial-program/national-map)及研究区所属政府数据门户 | 研究区范围内的高程、水系、交通等官方要素 | 先核对地域覆盖和产品说明；USGS 此产品主要面向美国，不能当作中国数据来源。各门户“可查看”不等于“可下载或公开再发布”。具体产品的版本、许可、水平/垂直基准逐项记录。 |

地形图应优先使用有明确产品版本、分辨率和垂直基准的 DEM。不要先任意指定一个全球 DEM 再假设目标地区、许可及访问条件均适用；需要登录或凭据的产品须依当前会话授权处理。行政图或交通图没有 DEM 时，不为装饰而补造地形。

## 3. 输入检查

- **GeoPackage**：列出图层名称和类型；明确用哪一层做研究区、行政背景或样点，不默认读第一层。
- **GeoJSON**：核对格式规范、坐标顺序和实际生产来源。文件扩展名不能证明上传者未把 GCJ-02 数值写入其中。
- **Shapefile ZIP**：至少核对同名 `.shp`、`.shx`、`.dbf`；检查 `.prj` 和编码信息。缺 `.prj` 时需要外部可信 CRS 依据。获授权解压时禁止路径穿越和覆盖原文件，在新目录操作。
- **GeoTIFF**：读取 CRS、范围、分辨率、波段、NoData、像元单位和垂直基准；无有效空间定位的普通影像不能直接当底图叠加。
- **CSV/Excel**：先明确工作表、坐标列、经纬度/投影单位、坐标来源、记录 ID；保留原始记录数。空坐标、重复 ID、疑似错列单独报告，不能无声丢弃。
- **远程引用**：上传文件可能指向在线图层、外部链接、VRT 数据源或在线瓦片；“本地文件”不等于加载时不会联网。禁止执行表格宏及文件内附带的脚本。

## 4. 每图层来源记录

以下字段与配置文件中的 `provenance` 对应，必须存在。缺乏证据时写 `unknown` 并解释，不造年份、精度或许可。

| 字段 | 记录内容 |
|---|---|
| `source` | 发布机构、数据集名称、产品页/精确 URL；上传数据写提供者与来源说明，不声称其已被官方验证 |
| `version` | 固定发布版、文件版本或快照标识；动态 URL 另记固定资产标识 |
| `year` | 数据代表的观测/有效年份或区间；与出版年、下载年分别记录 |
| `license` | 许可名称、条款链接及应保留的署名；用户限制或未知状态也必须写明 |
| `spatial_resolution` | 栅格像元大小、矢量编制比例尺或已知定位精度，注明单位及概念，不混用 |
| `acquired_at` | 实际获取/接收日期及必要的时区；未获取写 `unknown`，不能用文档访问日填充 |

获授权处理后，在交付记录中补充输入文件路径与校验值、原始/输出 CRS、转换方法、裁剪范围、重采样/简化参数、输出图层、软件版本。保存原始元数据及许可文本。未知许可不影响内部清点，但未明确允许前不能将相应原始数据打包公开再分发；清楚区分内部草图与可公开交付状态。

## 5. 获取与离线运行边界

1. 先检查本地可用资料与当前会话的授权，再决定下载。浏览公开文档不会赋予 GIS 数据下载、依赖安装、脚本执行、凭据读取或上传授权。已有明确授权在其范围内继续，不重复询问。
2. 无下载授权时生成来源清单和待获取计划，并继续配置、代码和静态审查；不要绕到其他服务或瓦片缓存悄悄获取。
3. 有获取授权时限制到必要范围，遵守端点速率/体积限制，缓存响应并固定版本；不得上传用户研究样点去第三方地理编码或坐标转换，除非上传本身也已获授权。
4. 离线绘图应只引用已核对的本地文件。Cartopy 的 `natural_earth()` 缺缓存时会下载和解压；`coastlines()`、`NaturalEarthFeature` 等也可能在渲染时触发获取。没有下载授权就不要调用这些隐式获取路径，使用显式本地几何。见 [Cartopy 官方说明](https://cartopy.readthedocs.io/stable/reference/generated/cartopy.io.shapereader.natural_earth.html)。
5. 缺少数据、下载失败或缓存不全时应失败并报告，不输出空白图却标作成功。公开数据工作流不等于“所有地区都可以自动获取完整数据”。
